# 내만세 · 내가 만드는 세상

> 아이디어는 내가, 제작은 내만세에서.

## 프로젝트 소개

- **서비스**: 내만세(내가 만드는 세상). 초등학생·중학생부터 대학생, 창업을 준비하는 누구나 쉽게 시제품을 제작할 수 있도록 돕는 3D 프린팅 제작 신청 서비스입니다.
- **사업 아이디어**: 머릿속 아이디어를 실물로 만들려면 장비와 비용, 업체를 찾는 수고가 필요합니다. 내만세는 '작은 공장' 역할을 맡아, 만들고 싶은 것과 용도·재료·수령 방법만 정하면 대신 제작해 줍니다. 수업 과제부터 공모전 출품작, 창업 시제품까지 한 곳에서 신청합니다.
- **주요 사용자**: 만들고 싶은 아이디어가 있지만 3D 프린터와 제작 경험이 없는 학생과 예비 창업자
- **서비스 목적**: 만들 것·용도·재료·수령 방법(보관·방문·택배)을 한 번에 정해 시제품 제작을 신청한다.
- **핵심 행동**: 소요시간 변동 안내에 동의하고 제작 신청을 끝까지 완료한다.
- **완료 조건**: 확인 화면에서 입력·선택한 내용을 검토하고 확정한 뒤, 접수 번호와 수령 안내, 용도별 다음 행동 안내가 있는 완료 화면에 도달한다.

## 사용자 흐름

```
진입            입력               선택                  확인               완료
소요시간 동의  → 만들 것 이름·    → 재료 선택,          → 신청 내용 확인   → 접수 번호,
+ 시작 버튼      제작 용도·          수령 방법 선택         + 확정 팝업        수령 안내,
                 신청자 이름 입력                                             용도별 다음 행동
                                    (직접 수령이면 날짜,
                                     택배면 주소)
```

- 성공 경로: 시작 → 만들 것 → 재료·수령 방법 → 내용 확인 → 확정 → 완료
- 수정 경로: 빈 입력이면 같은 단계에서 안내 후 수정 / 확인 화면에서 이전으로 돌아가 수정 / 팝업에서 "다시 확인하기"
- 다시 시작: 완료 화면의 "다른 것 만들기"로 흐름의 모든 값을 초기화

## 인터랙션 시나리오

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
| --- | --- | --- | --- | --- |
| 소요시간 변동 동의 체크 | change | 체크됨 | "동의하셨습니다" 문구가 초록색으로 바뀌고 시작 버튼 활성화 | 시작 가능 |
| 동의 체크 해제 | change | 체크 안 됨 | 안내 문구 원래대로, 시작 버튼 비활성화 | 시작 불가 |
| "제작 신청 시작하기" 클릭 | click | 없음 | 신청서 표시, 만들 것 이름 칸으로 포커스 | 1단계 |
| 신청자 이름 입력 | input | 없음 | 글자 수 `n / 10` 즉시 표시 | 1단계 유지 |
| 빈칸으로 "재료와 수령 방법 고르기" 클릭 | click | 만들 것 이름·제작 용도·신청자 이름 중 빈 값이 있음 (공백만 입력도 빈 값) | 칸마다 수정 방법 안내, 칸 테두리 빨간색, 첫 빈칸으로 포커스 | 1단계 유지 |
| 모두 입력 후 같은 버튼 클릭 | click | 세 값이 모두 있음 | 오류 지움 | 2단계 |
| 재료 변경 | change | 선택한 재료 | 재료별 제작 소요 안내 문구 변경 | 2단계 유지 |
| 수령 방법을 "추후 일정에 직접 수령"으로 변경 | change | 값이 visit | 방문 날짜 입력칸 표시 | 2단계 유지 |
| 수령 방법을 "택배"로 변경 | change | 값이 delivery | 받을 주소 입력칸 표시 (날짜 칸은 숨김) | 2단계 유지 |
| 수령 방법을 "보관"으로 변경 | change | 값이 locker | 날짜·주소 입력칸 숨기고 값·오류 지움 (검사에서도 제외) | 2단계 유지 |
| 날짜 없이 "신청 내용 확인하기" 클릭 | click | 직접 수령인데 날짜가 비었거나 오늘보다 이전 | 날짜 칸 아래 수정 방법 안내 | 2단계 유지 |
| 주소 없이 "신청 내용 확인하기" 클릭 | click | 택배인데 주소가 비었거나 8자 미만 | "주소를 입력해 주세요" 또는 "상세 주소까지 적어 주세요" 안내, 주소 칸으로 포커스 | 2단계 유지 |
| "신청 내용 확인하기" 클릭 | click | 통과 | 입력·선택 값을 확인 화면에 표시 | 3단계 |
| "수정하기"(이전) 클릭 | click | 없음 | 입력값을 유지한 채 이전 단계 표시 | 이전 단계 |
| "제작 신청하기" 클릭 | click | 없음 | 확인 팝업 열림 | 팝업 |
| 팝업 "다시 확인하기" 또는 Esc | click / keydown | 없음 | 팝업 닫힘, 값 유지 | 3단계 |
| 팝업 "신청 확정" | click | 수령 방법(보관·방문·택배), 제작 용도(과제·공모전·창업) | 접수 번호, 수령 방법별 안내(택배면 배송 안내), 용도별 다음 행동 안내 | 4단계(완료) |
| "다른 것 만들기" 클릭 | click | 없음 | 입력·선택·오류·요약·진행 표시 초기화 | 1단계 |
| 이메일 없이 "완료 알림 신청하기" | submit | 빈 값 또는 형식 오류 | 수정 방법 안내, 입력칸 빨간색 | 입력 유지 |
| 올바른 이메일로 신청 | submit | 형식 통과 | 성공 문구·초록 스타일, 버튼 "알림 신청 완료"로 비활성화 | 신청 완료 |

## 이전 주차에서 이어진 기능

- 2주차: 시맨틱 구조(header·nav·main·section·footer), 내부 이동 링크, 이미지와 대체 텍스트
- 3주차: 정보 위계, 카드 그룹, 버튼 hover·focus·active
- 4주차: viewport, 유동 너비, 기능 카드 자동 Grid, 768px 미디어 쿼리
- 5주차: 완료 알림 이메일 submit 처리와 피드백
- 6주차: 테마 전환(click), 글자 수(input), 소요시간 동의(change), 재료 안내 탭 3개

## 테스트 결과

| 구분 | 확인한 조작 | 결과 |
| --- | --- | --- |
| 정상 경로 | 소요시간 동의 → 시작 → 만들 것·용도·이름 입력 → 재료·수령 → 확인 → 확정 → 완료 | 통과 |
| 빈 입력 | 세 칸을 비우고 다음 클릭, 공백만 입력하고 다음 클릭, 용도만 비우고 다음 클릭 | 통과 (1단계 유지, 안내 표시) |
| 조건부 입력 | 직접 수령은 날짜 칸, 택배는 주소 칸만 표시, 다른 방법으로 바꾸면 숨김·초기화 | 통과 |
| 날짜 검사 | 날짜 없이 다음, 지난 날짜로 다음 | 통과 (2단계 유지, 안내 표시) |
| 택배 주소 검사 | 주소 없이 다음, "서울시"처럼 짧게 입력하고 다음, 상세 주소까지 입력하고 다음 | 통과 (빈 값·짧은 값은 2단계 유지, 정상 값은 확인 화면에 주소 표시) |
| 택배 완료 | 택배로 신청 확정 | 통과 (완료 화면에 배송 안내) |
| 이전·수정 | 확인 화면에서 이전 → 값 유지 → 만들 것 이름 수정 → 확인 화면에 반영 | 통과 |
| 용도별 안내 | 창업 시제품으로 신청 → 완료 화면에 사용자 반응 기록 안내 | 통과 |
| 팝업 취소 | "다시 확인하기"와 Esc | 통과 (3단계와 값 유지) |
| 다시 시작 | 완료 후 "다른 것 만들기" | 통과 (모든 값·오류·진행 초기화) |
| 기존 기능 | 테마 전환(버튼 문구 함께 변경), 탭 3개, 글자 수, 이메일 알림 신청 | 통과 |
