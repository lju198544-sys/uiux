# 내만세 (내가 만드는 세상)

## 프로젝트 소개

- 서비스: 내만세(내가 만드는 세상). 만들고 싶은 것을 신청하면 3D 프린터로 대신 만들어 주는 시제품 제작 신청 서비스입니다.
- 주요 사용자: 만들고 싶은 아이디어는 있지만 3D 프린터가 없는 학생(초·중·대학생)과 창업을 준비하는 사람
- 목적: 만들 것, 용도, 재료, 받는 방법을 정해서 제작을 신청한다.
- 핵심 행동: 제작 신청을 처음부터 끝까지 완료하기
- 완료 조건: 신청 내용을 확인하고 확정하면 접수 번호가 있는 완료 화면이 나온다.

## 사용자 흐름

진입 → 입력 → 선택 → 확인 → 완료

1. 진입: 소요시간 안내에 동의하고 "제작 신청 시작하기"를 누릅니다.
2. 입력: 만들 것 이름, 제작 용도, 신청자 이름을 적습니다. 빈칸이 있으면 다음으로 넘어가지 않습니다.
3. 선택: 재료(PLA·TPU·레진)와 받는 방법(보관·직접 방문·택배)을 고릅니다.
   - 직접 방문을 고르면 방문 날짜 칸이 나옵니다.
   - 택배를 고르면 받을 주소 칸이 나옵니다.
4. 확인: 지금까지 적은 내용을 확인합니다. 틀린 곳은 이전 단계로 돌아가 고칠 수 있습니다.
5. 완료: 확인 팝업에서 "신청 확정"을 누르면 접수 번호가 나옵니다. "다른 것 만들기"로 다시 신청할 수 있습니다.

## 인터랙션 시나리오

행동 → 이벤트 → 조건 → 화면 반응 → 다음 상태

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
| --- | --- | --- | --- | --- |
| 동의 체크박스를 누른다 | change | 체크했는가? | 안내 문구가 바뀌고 시작 버튼이 눌리게 된다 | 시작 가능 |
| "제작 신청 시작하기"를 누른다 | click | - | 신청서가 나타난다 | 입력 단계 |
| 신청자 이름을 입력한다 | input | 몇 글자인가? | "3 / 10"처럼 글자 수가 바로 바뀐다 | 입력 단계 유지 |
| 빈칸이 있는데 다음을 누른다 | click | 이름이나 용도가 비어 있는가? | 칸 아래에 무엇을 적어야 하는지 빨간 글씨로 알려 준다 | 입력 단계 유지 |
| 다 적고 다음을 누른다 | click | 빈칸이 없는가? | 빨간 글씨가 사라진다 | 선택 단계 |
| 받는 방법을 바꾼다 | change | 방문인가? 택배인가? | 방문이면 날짜 칸, 택배면 주소 칸이 나온다 | 선택 단계 유지 |
| 날짜나 주소 없이 다음을 누른다 | click | 필요한 칸이 비었거나 맞지 않는가? | 날짜를 골라 달라고, 또는 주소를 자세히 적어 달라고 알려 준다 | 선택 단계 유지 |
| "신청 내용 확인하기"를 누른다 | click | 모두 맞게 적었는가? | 적은 내용을 한 번에 보여 준다 | 확인 단계 |
| "제작 신청하기"를 누른다 | click | - | "이대로 제작을 신청할까요?" 팝업이 뜬다 | 팝업 |
| 팝업에서 "신청 확정"을 누른다 | click | - | 접수 번호와 받는 방법 안내가 나온다 | 완료 |

### 분기 시나리오

빈 입력 · 확인 취소 · 이전 · 다시 시작

- 빈 입력: 만들 것 이름 없이 다음을 누르면 현재 화면에 머물고 "만들 것 이름을 입력해 주세요."라고 알려 줍니다. 입력한 뒤 다시 누르면 선택 단계로 넘어갑니다. 택배를 골랐는데 주소가 없을 때도 같은 방법으로 알려 줍니다.
- 확인 취소: 확인 팝업에서 "다시 확인하기"를 누르면 팝업만 닫히고 적은 내용은 그대로 남아 있습니다.
- 이전: 확인 화면에서 수정하기를 누르면 이전 단계로 돌아가고, 적었던 값은 지워지지 않습니다. 고친 내용은 확인 화면에 다시 반영됩니다.
- 다시 시작: 완료 화면에서 "다른 것 만들기"를 누르면 적은 값, 빨간 안내 글씨, 고른 항목, 진행 단계가 모두 처음으로 돌아갑니다.
