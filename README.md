# 내만세 · 내가 만드는 세상

> 아이디어는 내가, 생산은 캠퍼스가.

## 프로젝트 소개

- **서비스**: 내만세(내가 만드는 세상). 학교 메이커스페이스의 3D 프린터를 학생 누구나 '나만의 작은 공장'처럼 쓰도록 연결하는 캠퍼스 제작 신청 서비스입니다.
- **사업 아이디어**: 시제품을 외부 업체에 맡기면 견적과 대기에 시간과 비용이 듭니다. 학교에는 이미 장비가 있지만 신청 방법이 번거로워 잘 쓰이지 않습니다. 내만세는 이 장비를 온라인 신청으로 열어, 학교라는 공간을 학생의 아이디어 생산 거점으로 바꿉니다.
- **주요 사용자**: 아이디어를 실물로 만들어 보고 싶지만 장비와 비용이 부담되는 대학생 (수업 과제, 동아리·공모전, 창업 준비)
- **서비스 목적**: 메이커스페이스에 직접 가지 않고도 만들 것·용도·재료·수령 방법을 한 번에 정해 제작을 신청한다.
- **핵심 행동**: 안전 수칙을 확인하고 제작 신청을 끝까지 완료한다.
- **완료 조건**: 확인 화면에서 입력·선택한 내용을 검토하고 확정한 뒤, 접수 번호와 수령 안내, 용도별 다음 행동 안내가 있는 완료 화면에 도달한다.

## 사용자 흐름

```
진입            입력               선택                  확인               완료
안전 수칙 확인 → 만들 것 이름·    → 재료 선택,          → 신청 내용 확인   → 접수 번호,
+ 시작 버튼      제작 용도·          수령 방법 선택         + 확정 팝업        수령 안내,
                 신청자 이름 입력                                             용도별 다음 행동
                                    (직접 수령이면 날짜)
```

- 성공 경로: 시작 → 만들 것 → 재료·수령 방법 → 내용 확인 → 확정 → 완료
- 수정 경로: 빈 입력이면 같은 단계에서 안내 후 수정 / 확인 화면에서 이전으로 돌아가 수정 / 팝업에서 "다시 확인하기"
- 다시 시작: 완료 화면의 "다른 것 만들기"로 흐름의 모든 값을 초기화

## 인터랙션 시나리오

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
| --- | --- | --- | --- | --- |
| 안전 수칙 체크박스 선택 | change | 체크됨 | 안내 문구가 초록색으로 바뀌고 시작 버튼 활성화 | 시작 가능 |
| 안전 수칙 체크 해제 | change | 체크 안 됨 | 안내 문구 원래대로, 시작 버튼 비활성화 | 시작 불가 |
| "제작 신청 시작하기" 클릭 | click | 없음 | 신청서 표시, 만들 것 이름 칸으로 포커스 | 1단계 |
| 신청자 이름 입력 | input | 없음 | 글자 수 `n / 10` 즉시 표시 | 1단계 유지 |
| 빈칸으로 "재료와 수령 방법 고르기" 클릭 | click | 만들 것 이름·제작 용도·신청자 이름 중 빈 값이 있음 (공백만 입력도 빈 값) | 칸마다 수정 방법 안내, 칸 테두리 빨간색, 첫 빈칸으로 포커스 | 1단계 유지 |
| 모두 입력 후 같은 버튼 클릭 | click | 세 값이 모두 있음 | 오류 지움 | 2단계 |
| 재료 변경 | change | 선택한 재료 | 재료별 출력 소요 안내 문구 변경 | 2단계 유지 |
| 수령 방법을 "직접 수령"으로 변경 | change | 값이 visit | 방문 날짜 입력칸 표시 | 2단계 유지 |
| 수령 방법을 "사물함 보관"으로 변경 | change | 값이 locker | 날짜 입력칸 숨기고 값·오류 지움 (검사에서도 제외) | 2단계 유지 |
| 날짜 없이 "신청 내용 확인하기" 클릭 | click | 직접 수령인데 날짜가 비었거나 오늘보다 이전 | 날짜 칸 아래 수정 방법 안내 | 2단계 유지 |
| "신청 내용 확인하기" 클릭 | click | 통과 | 입력·선택 값을 확인 화면에 표시 | 3단계 |
| "수정하기"(이전) 클릭 | click | 없음 | 입력값을 유지한 채 이전 단계 표시 | 이전 단계 |
| "출력 신청하기" 클릭 | click | 없음 | 확인 팝업 열림 | 팝업 |
| 팝업 "다시 확인하기" 또는 Esc | click / keydown | 없음 | 팝업 닫힘, 값 유지 | 3단계 |
| 팝업 "신청 확정" | click | 제작 용도 (과제·공모전·창업) | 접수 번호, 수령 방법별 안내, 용도별 다음 행동 안내 | 4단계(완료) |
| "다른 것 만들기" 클릭 | click | 없음 | 입력·선택·오류·요약·진행 표시 초기화 | 1단계 |
| 이메일 없이 "완료 알림 신청하기" | submit | 빈 값 또는 형식 오류 | 수정 방법 안내, 입력칸 빨간색 | 입력 유지 |
| 올바른 이메일로 신청 | submit | 형식 통과 | 성공 문구·초록 스타일, 버튼 "알림 신청 완료"로 비활성화 | 신청 완료 |

## 이전 주차에서 이어진 기능

- 2주차: 시맨틱 구조(header·nav·main·section·footer), 내부 이동 링크, 이미지와 대체 텍스트
- 3주차: 정보 위계, 카드 그룹, 버튼 hover·focus·active
- 4주차: viewport, 유동 너비, 기능 카드 자동 Grid, 768px 미디어 쿼리
- 5주차: 완료 알림 이메일 submit 처리와 피드백
- 6주차: 테마 전환(click), 글자 수(input), 안전 수칙(change), 재료 안내 탭 3개
